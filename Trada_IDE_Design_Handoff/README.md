# Trada — IDE Agent Design Handoff

**Scope:** Product design conversation from the request to redo authentication pages through the full admin menu page design (November 2026). This handoff contains **reference PNG images**, requirements, and agent instructions. The PNGs are visual references, **not editable Figma files or working frontend code**.

## Start here
1. Read `PRODUCT_CONTEXT.md` and `DESIGN_SYSTEM.md`.
2. Read `SCREENS_AND_FLOWS.md` and `AGENT_IMPLEMENTATION.md`.
3. Inspect `design-manifest.json` and all PNGs in `assets/`; prioritize images marked **preferred**.
4. Implement actual responsive screens, not a flattened mockup or a collage.

## Important boundaries
- Trada is the brand; **Trada AI** is the marketing description of its assistant, not necessarily a legal/product rename.
- **Deep Navy + Calm Teal + White** are the approved colours. Avoid olive or unrelated palettes.
- All values, business names, customer names, statuses, and transaction records in the images are **illustrative**.
- BNPL is partner-dependent and must not be represented as live until integration is confirmed.
- No exact production colour hex, logo vector, API contract, or working code was supplied in this portion of the conversation; do not assume those are finalized.
- Admin permissions, data handling, financial definitions and feature readiness require implementation validation.

## Contents
- `assets/`: full-resolution available reference images.
- `design-manifest.json`: provenance, dimensions, status and checksums.
- `PRODUCT_CONTEXT.md`: decisions, business requirements and caveats.
- `DESIGN_SYSTEM.md`: visual and responsive guidelines.
- `SCREENS_AND_FLOWS.md`: screen inventory, navigation and workflows.
- `AGENT_IMPLEMENTATION.md`: implementation tasks and acceptance criteria.
